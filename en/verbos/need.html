Como usar “to need”

"Need" é "precisar" ou "necessitar". Funciona com substantivo ("I need help") ou com "to + verbo" ("I need to go"). Na negativa, "don't need to" é "não precisa": "You don't need to come".

Uma construção que surpreende brasileiros é "something needs + -ing" com sentido passivo: "The car needs washing" (o carro precisa ser lavado). Como substantivo, "need" é necessidade: "there's no need" (não precisa).

Exemplos com tradução

  • I need a coffee.
    Preciso de um café.
  • You need to rest more.
    Você precisa descansar mais.
  • Do you need any help?
    Você precisa de ajuda?
  • You don't need to bring anything.
    Você não precisa levar nada.
  • The walls need painting.
    As paredes precisam de pintura.
  • We'll need more chairs if everyone comes.
    Vamos precisar de mais cadeiras se todo mundo vier.

Dicas para brasileiros

  • Sem preposição antes do substantivo: "I need money", nunca "I need of money".
  • Com verbo, use "to": "I need to study". "I need study" está errado.
  • "There's no need to…" é uma forma gentil de dizer "não precisa…": "There's no need to apologize".
