Como usar “to build”

"Build" é construir: casas, pontes, móveis, mas também coisas abstratas como uma carreira, uma relação de confiança ou uma empresa ("build a business"). É irregular: build, built, built.

Com "up", ganha a ideia de acumular ou aumentar aos poucos: "build up strength" (ganhar força), "Tension was building up" (a tensão estava aumentando).

Exemplos com tradução

  • They're building a new school near my house.
    Estão construindo uma escola nova perto de casa.
  • My father built this table himself.
    Meu pai construiu esta mesa sozinho.
  • The bridge was built in 1974.
    A ponte foi construída em 1974.
  • It takes years to build trust.
    Leva anos para construir confiança.
  • She has built a successful career in law.
    Ela construiu uma carreira de sucesso no direito.
  • Pressure had been building up for weeks.
    A pressão vinha aumentando havia semanas.

Dicas para brasileiros

  • O "u" de build não é pronunciado: diz-se "bild". Built soa como "bilt".
  • "Building" também é substantivo: prédio, edifício.
  • Na academia, "build muscle" é ganhar massa muscular.
