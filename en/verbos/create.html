Como usar “to create”

"Create" é criar: fazer existir algo novo, seja uma obra, um produto, empregos ou um problema. É comum em contextos de arte, tecnologia e negócios: "create an account" (criar uma conta), "create jobs" (gerar empregos).

Também se usa para efeitos e sentimentos: "create a good impression", "create confusion". Pronúncia: /kriˈeɪt/, kri-ÊIT, com acento na segunda sílaba. O substantivo é "creation" e o adjetivo "creative".

Exemplos com tradução

  • Click here to create an account.
    Clique aqui para criar uma conta.
  • The project will create 500 new jobs.
    O projeto vai gerar 500 novos empregos.
  • She creates beautiful sculptures from recycled metal.
    Ela cria esculturas lindas com metal reciclado.
  • His comments created a lot of confusion.
    Os comentários dele causaram muita confusão.
  • The app was created by two students.
    O aplicativo foi criado por dois estudantes.
  • We want to create a space where everyone feels welcome.
    Queremos criar um espaço onde todos se sintam bem-vindos.

Dicas para brasileiros

  • Pronúncia: kri-ÊIT, duas sílabas, acento no final.
  • Para "criar filhos", não use "create": diga "raise" ou "bring up" ("She raised three kids").
  • "Create a fuss" ou "make a fuss" = fazer escândalo.
