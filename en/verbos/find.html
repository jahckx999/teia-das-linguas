Como usar “to find”

"Find" é encontrar ou achar algo, seja procurando, seja por acaso. Diferente de "meet", que é encontrar pessoas (conhecer ou se reunir), "find" é para objetos, informações, soluções e lugares: "I can't find my keys".

Muito útil para brasileiros é o uso de "find" para dar opinião: "I find this book boring" significa "acho este livro chato". Nesse sentido, "find" mostra uma impressão pessoal baseada na experiência. E "find out" é descobrir uma informação.

Exemplos com tradução

  • I can't find my glasses.
    Não consigo achar meus óculos.
  • Did you find a parking space?
    Você achou uma vaga para estacionar?
  • We found a great restaurant near the hotel.
    Encontramos um restaurante ótimo perto do hotel.
  • I find it hard to wake up early.
    Acho difícil acordar cedo.
  • She found out the truth last week.
    Ela descobriu a verdade semana passada.
  • The jury found him not guilty.
    O júri o considerou inocente.

Dicas para brasileiros

  • Pessoas você "meet"; coisas e informações você "find". "Vou encontrar meus amigos" é "I'm meeting my friends".
  • Para opinião baseada em experiência, use "find + objeto + adjetivo": "I found the movie funny". Repare que não precisa de "to be".
  • "Find out" é descobrir uma informação; "discover" é mais para descobertas científicas ou algo que ninguém sabia.
