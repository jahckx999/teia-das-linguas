Como usar “to set”

"Set" é um dos verbos com mais sentidos do inglês. O básico é colocar ou posicionar algo com cuidado: "set the table" (pôr a mesa), "set the glass down" (pousar o copo). Daí vêm definir e estabelecer: "set a goal" (definir uma meta), "set a date" (marcar uma data), "set a record" (estabelecer um recorde).

Também significa ajustar aparelhos ("set the alarm", programar o despertador) e, para o sol, pôr-se: "The sun sets at six". As três formas são iguais: set, set, set.

Exemplos com tradução

  • Can you set the table, please?
    Você pode pôr a mesa, por favor?
  • I set my alarm for 6 a.m.
    Programei meu despertador para as 6 da manhã.
  • The sun sets earlier in winter.
    O sol se põe mais cedo no inverno.
  • We need to set a date for the meeting.
    Precisamos marcar uma data para a reunião.
  • She set a new world record last year.
    Ela estabeleceu um novo recorde mundial no ano passado.
  • The film is set in São Paulo in the 1970s.
    O filme se passa em São Paulo nos anos 1970.

Dicas para brasileiros

  • Como set não muda no passado, o contexto decide o tempo: "I set the alarm every night" (presente) x "I set the alarm last night" (passado). Na 3ª pessoa do presente, lembre o -s: "She sets".
  • "Be set in" indica onde ou quando uma história acontece: "The novel is set in Lisbon" (o romance se passa em Lisboa).
  • Não confunda com "sit" (sentar): "set" pede objeto (você coloca algo), "sit" não.
